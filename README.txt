NETWORK INTRUSION DETECTION SYSTEM

1. PROJECT TITLE
Python-Based Network Intrusion Detection System

2. PROJECT OBJECTIVE
The objective of this project is to develop a basic Network Intrusion
Detection System (IDS) using Python and Scapy. The system monitors
network traffic, analyzes packets, detects suspicious high packet rates,
generates alerts, and creates a graphical report of detected network
events.

3. TECHNOLOGIES USED
- Python
- Scapy
- Matplotlib
- VS Code
- Npcap
- Windows PowerShell

4. PROJECT FILES

ids.py
Captures and analyzes network packets. It identifies source IP,
destination IP, and protocol information.

detection_rules.py
Contains the detection rules used to identify suspicious network
activity such as unusually high packet rates.

test_detection.py
Tests the detection rule using sample packet activity and verifies
that an alert is generated.

alerts.log
Stores alerts generated by the intrusion detection system with
timestamps and source IP addresses.

dashboard.py
Reads the alert log and generates a graphical report showing the
number of alerts associated with each source IP address.

intrusion_report.png
Graphical visualization of detected network intrusion alerts.

5. HOW THE SYSTEM WORKS

Step 1:
The IDS captures network packets using the Scapy library.

Step 2:
The captured packets are analyzed to identify source IP,
destination IP, and protocol type.

Step 3:
The detection rule monitors packet activity and checks for
unusually high packet rates.

Step 4:
When suspicious activity is detected, an alert is generated.

Step 5:
The alert is stored in the alerts.log file.

Step 6:
The dashboard reads the alert log and creates a graphical report
showing the detected alerts.

6. DETECTION RULE

The implemented detection rule identifies a high packet rate from
a source IP address within a defined time period.

Example:
If more than the configured number of packets are detected from
a source within the monitoring period, the system generates a
high packet rate alert.

7. ALERT GENERATION

The system generates alerts in the following format:

[ALERT] High packet rate detected from <Source IP>

The alerts are stored in alerts.log for later analysis.

8. GRAPHICAL REPORT

The dashboard.py program uses Matplotlib to visualize the number
of alerts generated by different source IP addresses.

The generated graph is saved as:

intrusion_report.png

9. HOW TO RUN THE PROJECT

Install the required libraries:

python -m pip install scapy
python -m pip install matplotlib

Run the network monitoring program:

python ids.py

Run the detection rule test:

python test_detection.py

Generate the graphical report:

python dashboard.py

10. TESTING

The detection rule was tested using test_detection.py.

The test successfully generated a high packet rate alert and
confirmed that the detection rule works correctly.

11. SECURITY BENEFITS

- Monitors network traffic.
- Identifies unusual packet activity.
- Generates alerts for suspicious traffic.
- Maintains an alert log for analysis.
- Provides a graphical representation of network events.

12. LIMITATIONS

This is an educational IDS prototype. It uses a basic packet-rate
detection rule and is not intended to replace a production IDS such
as Snort or Suricata.

13. CONCLUSION

The project demonstrates how Python and Scapy can be used to build
a basic network intrusion detection system. The system captures
network traffic, analyzes packets, detects suspicious activity,
generates alerts, records security events, and visualizes the
detected alerts using a graphical report.
